# 漫才つかみクイズ

M-1グランプリ決勝ネタの冒頭の一言から、演じたコンビを当てるスマートフォン向けのテキストクイズです。これは非公式のファンクイズであり、M-1グランプリおよび関係各社とは関係ありません。

収録しているのは決勝ネタ47本（2001–2010年：19本、2015–2025年：28本）の冒頭最大10行です（45本が10行、残り2本は演者名が出る手前まで）。台詞は記憶から再構成せず、すべて書き起こしページから引用し、各問題の解答に出典URLを表示しています。公式動画へのリンク欄（`video_url`）はありますが、M-1グランプリ公式YouTubeチャンネルは決勝ネタを公開していないため、現在はすべて `null` です。

## ローカルで実行

```sh
python3 -m http.server 8123
```

ブラウザで `http://localhost:8123/` を開いてください。

## テスト

```sh
node --test tests/
node tools/check_data.mjs
```

## データの検証（ローカルのみ）

`data/acts.json` の各ネタは、次の3つの機械チェックを通ったものだけです。

1. **逐語一致**: `tools/verify_sources.py data/acts.json` が出典ページを取得し、引用した各行がページ本文にそのまま含まれるか確認（NFKC正規化と空白除去のみ。あいまい一致なし）。
2. **年・ラウンド**: `tools/wiki_oracle.py` で、日本語版Wikipedia「M-1グランプリ」の歴代決勝戦結果と照合（その年の決勝進出者か、最終決戦に進んだか）。
3. **スキーマ**: `node tools/check_data.mjs`。

候補の収集（`tools/resolve_candidates.py`、`tools/assemble.py`、`tools/build_data.py`）は `research/`（Git管理外）を使います。
